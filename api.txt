# Regenerate with: go test . -run TestAPIGolden -update-api
#
# "package pgmigrate" is the facade a consumer imports; "package
# pgmigratetest" is the conformance suite it runs against its own handle.
# The internal packages are listed too, because the facade re-exports their
# types as aliases: a change to one of those signatures changes what a
# consumer sees, even though the import path itself is private. Growing this
# file is a reviewed diff — see CHARTER.md.
